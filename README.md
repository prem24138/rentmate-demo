# RentMate

RentMate is a full-stack rental platform that enables users to rent products or list their own items for rent. The platform aims to make renting simple, affordable, and sustainable by connecting renters with product owners through an intuitive web interface.

## Features

- User authentication and authorization
- Browse and search rental products
- List products for rent
- Product details with images and pricing
- Booking and rental management
- User profile management
- Responsive and modern UI

## Tech Stack

### Frontend
- React.js
- Tailwind CSS

### Database & Authentication
- Firebase Authentication
- Firebase Firestore

## Project Goal

The primary goal of RentMate is to promote the sharing economy by providing a secure and user-friendly platform where users can rent items instead of purchasing them. This helps reduce unnecessary expenses while encouraging sustainable resource utilization.
